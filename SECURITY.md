# Security and Project Data

Do not commit or share:

- Runtime `config/raid-config.json`.
- Project Workback or RAID workbooks.
- Meeting Monitor artifacts.
- Email or Teams exports.
- Proposals, approvals, audits, and backups.
- Personal paths, mailbox addresses, tenant links, credentials, or tokens.

Use synthetic data for tests and examples. Report vulnerabilities privately to the repository owner. Do not include private project data in a public issue.
