# RAID Review Agent Roadmap

## Phase 1: Foundation

- Define package structure and configuration schema.
- Add the included Workback and RAID template after sanitization and structural validation.
- Implement one-command local setup.
- Add read-only workbook inspection.

## Phase 2: Review

- Add configurable project scope and exclusions.
- Read Meeting Monitor and additional knowledge-base folders.
- Add optional WorkIQ meeting, email, and Teams retrieval.
- Produce evidence-grounded Markdown and JSON proposals.

## Phase 3: Approval

- Add item-by-item approve, edit, reject, defer, and more-evidence dispositions.
- Persist a validated approval manifest.
- Bind approval to proposal and workbook fingerprints.

## Phase 4: Apply

- Add deterministic workbook writes.
- Support new-copy and current-workbook modes.
- Require timestamped backups.
- Preserve supported workbook structures and formatting.
- Reopen and validate every approved write.

## Phase 5: Release

- Add synthetic workbook fixtures and tests.
- Add release ZIP builder.
- Add GitHub Actions validation.
- Publish the first pre-release.
- Complete security and installation documentation.
- Select and add a reuse license before stable release.
